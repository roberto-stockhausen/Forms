Criando formulários com HTML

Para criar um formulário, se usa a tag FORM

Usando a tag input, podemos pedir uma informação ao usuário. Ela tem alguns atributos, com o principal sendo "type", que indica que tipo de input será usado:

Input type="text" cria uma caixa de texto:


Podemos adicionar o atributo "id" no input. Será útil mais tarde.

Com o atributo value, podemos adicionar uma resposta padrão a caixa de texto. Nesse caso, value="Insira nome aqui"

Usando o type="radio", podemos criar uma pergunta objetiva onde apenas uma resposta é selecionável:

Qual a palavra mais difícil de falar?





Com o atributo "name" podemos definir de qual questão a alternativa é. Se cada opção tiver um "name" diferente, todas elas serão selecionáveis:

Qual a palavra mais difícil de falar?





Sem usar line break, podemos até fazer opções horizontais:

Rate this form:



Com a tag "checkbox" é possível criar opções de mulipla escolha, ou opções que podem ser marcadas e desmarcadas
