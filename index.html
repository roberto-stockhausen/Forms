Criando formulários com HTML

Para criar um formulário, se usa a tag "FORM"

Essa tag define o espaço do formulário. Dentro dele serão colocados todas as tags que compõe-o. Também é importante colocar alguns atributos.

O atributo "action" Define para onde as informações do formulário serão enviadas ao clicar no "submit". Normalmente é um servidor que possa processar essa informação ou arquivo relacionado a página com o formulário, talvez um arquivo .php

"method" Indica de que forma essas informações serão enviadas. "method="get" envia-os por meio de um URL, enquanto method="post" faz um pedido de HTTP.

Para criar um dos campos do formulário, se usa a tag "INPUT"

Com o type="submit", podemos enviar as informações dentro do form para o destino definido.



Para criar as legendas de cada input, se usa a tag "LABEL"

Ela foi usada até agora para informar o usuário o que cada opção representa.

A Label se destaca pelo atributo "for", onde você indica de qual input essa label é. Dentro desse "for" podemos colocar o id de um input. Isso faz com que clicar no conteúdo da label acesse ou ative o input.




Para criar caixas de texto maiores, se usa a tag "TEXTAREA"

É recomendada para inputs de texto de múltiplas linhas e parágrafos, como redações ou feedbacks.

Para criar um botão que faz alguma coisa ao ser clicado, usamos a tag "BUTTOM"

Costumamos usar ela para executar funções de javascript usando o atributo "onclick", mas no contexto de formulário, ele é uma alternativa ao input type="submit", que pode enviar pedidos http para enviar informações de um formulário preenchido.
